Pasos para Compilar tu APK en GitHub Actions (100% Automático)

1
Sube estos archivos a tu repositorio de GitHub manteniendo la estructura de carpetas: package.json, capacitor.config.json, www/ y .github/workflows/build-apk.yml.
2
Ve a la pestaña Actions en tu repositorio de GitHub. Verás el flujo "Build Android APK (Capacitor)".
3
Haz clic en Run workflow (o simplemente haz un git push). GitHub Actions instalará Node 20, Java JDK 17, Android SDK y ejecutará ./gradlew assembleDebug.
4
Al finalizar, en la sección Artifacts encontrarás tu archivo gg-keymapper-debug-apk.zip listo para descargar e instalar en tu teléfono o emulador Android.
